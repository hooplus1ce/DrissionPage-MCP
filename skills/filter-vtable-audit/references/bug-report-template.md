## 严重度与优先级约定（禅道）
| 级别 | 语义 | 适用示例 |
|---|---|---|
| 1 致命 / P1 | 主流程不可用、数据丢失 | 少见 |
| 2 严重 / P2 | 功能结果错误、数据错乱、字典值无法对应 | 客户等级编码未翻译、状态字典文案两套 |
| 3 一般 / P3 | 功能缺失但可绕过、一致性破坏 | 有筛选项无列表列 / 有列表列无筛选项 |
| 4 轻微 / P4 | 文案/命名不统一 | 销售区域名称 vs 销售区域 |

## 5 类典型 BUG 成例（字段措辞可复用）
1. **字典编码未翻译**：列显示数字/代码(1,2,3)，下拉为翻译文案("1级"…)。标题：`【模块-列表】<字段>列显示原始编码，与筛选下拉待选值不一致`。
2. **字典文案两套**：列值 {未审批,已审批} vs 下拉 {待审核,已审核} 零交集。标题：`【模块-列表】<字段>列值与筛选下拉字典文案不统一`。
3. **筛选独有无列**：筛选项存在、VTable 26 列无对应展示列。标题：`【模块-列表】筛选区提供"<字段1>""<字段2>"筛选项，但列表无对应列展示`。
4. **列独有无筛选**：列表有列（含 field 名）但筛选区无筛选项；若列值全空另注"疑似列配置/数据填充遗漏，需一并排查"。标题：`【模块-列表】列表展示"<字段>"列，但筛选区无对应筛选项`。
5. **命名不一致**：筛选"销售区域名称" vs 列"销售区域"。标题：`【模块-列表】同一字段在筛选区与列表命名不统一`。
